# 13 工资表导出验收（2026-09-30）

## 已确认边界

用户确认：仅导出已锁定的有效批次，包含正常工资、更正和独立补发；所选范围任一未锁定批次阻止生成；无工资主体跳过并提示，全范围无工资拒绝生成。更正锁定生效后只取新版本，补发独立列行，人数按员工去重。未知个税留空；零工资保留并提示，缺银行卡不阻断工资表（代发规则属于需求 14）。

重试同一个 request_id 返回原导出记录；改变范围必须使用新编号。失败或进程中断后，用户重新生成得到新记录。文件生成前保存批次/试算 ID、确认输入指纹、记录 ID、参数与模板哈希版本；生成阶段不持有数据库事务，完成前和下载时重新核对有效版本。中断的 started 记录不可下载，页面明确提示重新生成。文件采用临时写入后原子改名，下载前校验 SHA-256。

文件名：`工资表-YYYY-MM-导出ID-未扣个税.xlsx`。Compose 使用独立本地卷保存生成文件，并显式配置 `/app/data/exports`。

## 模板适配审计

原件 `docs/工资表模板.xlsx` 保持不变。`backend/scripts/prepare_payroll_template.py` 可重建打包在后端的运行模板；不直接把原件中的历史人员和税务数据提供给用户。

- 保留全部 23 张工作表、表头顺序、合并范围与样式。工资表 AX 列、工资条 U 列、汇总 C 列改标“未扣个税金额”。
- 原工资合计行 SUBTOTAL 只引用第 2—3 行表头，不能沿用；现覆盖第 5 行至实际末行。扩行复制模板样式。
- 汇总原公式绑定演示主体、全列和固定位置，改为按主体 ID 排序后的实际行范围 SUM，避免同名主体和通配字符误计。保留总计公式。
- 原辅助页中与历史样例绑定的查找、税务及成本计算不作为本需求的可验证公式。清除这些样例行的值和公式，辅助页结构保留并在导出报告提示未填充；本需求不执行个税、代发或研发项目计算。
- 可独立验证的序号 `ROW()-1` 保留计算逻辑，增加空行保护；中汽页填写说明保留。税务和无来源字段留空，不用公式得到零来替代未知税额。
- 工资明细及工资条金额直接写入 Decimal 台账快照，不依赖 Excel 重算；汇总公式需 Excel 打开时重算。未宣称 openpyxl 计算了公式缓存。

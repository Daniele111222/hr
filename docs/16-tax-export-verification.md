# 16 申报辅助模板导出验收（2026-10-02）

## 实现与字段来源

新增 `/exports/tax` 与导出中心申报辅助选项，复用需求 13 的有效锁定台账、短事务生成、请求编号重试、失败报告、版本复核和下载校验。没有新增 schema、运行时依赖、个税计算或回填流程。

| 原模板列 | 填充来源与边界 |
| --- | --- |
| A 工号、B 姓名、D 证件号码 | 锁定员工快照，按文本写入；工号无来源留空并提示 |
| G 本期收入 | 锁定应发金额，不使用扣除个人缴费后的未扣个税金额替代；只作为线下核对来源，不宣称为最终申报收入 |
| I 基本养老、J 基本医疗、K 失业保险、L 公积金 | 仅映射锁定项目 `social_employee_pension`、`social_employee_medical`、`social_employee_unemployment`、`housing_employee`；未出现的项目留空，存在且为零的项目可填零；不重新计算缴费 |
| AG 备注 | 主体、工资期间、批次号、更正来源或补发原因、未扣个税金额及“未完成税务申报”说明 |
| C、E、F、H、M—AF | 证件类型、所得期间起止、免税收入、累计扣除、税前扣除合计、税额等 24 项无申报来源，保持空白，导出报告按列逐项提示 |

所得期间不从工资期间或发放日期推断；工资期间只在备注保存。正常工资与补发按有效批次单列，避免未确认的申报合并规则。更正只取最新有效版本；补发没有重新计算个人缴费，其缺来源缴费单元格留空。自由险种代码不按名称猜测养老/医疗/失业归属，发出 `SOCIAL_ITEM_UNMAPPED`；缺分项逐项发出 `DEDUCTION_SOURCE_MISSING`。

文件名、备注、页脚、页面提示和报告明确“未扣个税金额”“申报辅助”“未完成税务申报”。用户需在线下补充并核对，暂不回填系统。

## 旧式模板实际核对

`backend/scripts/prepare_tax_template.py` 调用 LibreOffice `soffice --headless --convert-to xlsx` 做真实格式转换，再用 openpyxl 核对并保存运行模板 `tax-v1.xlsx`。LibreOffice 只用于模板准备和本次验收，运行服务直接读取已打包的 xlsx。

原始 `docs/正常工资薪金所得_模板.xls` 保留不变，SHA-256：`082b43f219d16402b576c707c3ac01f6ca94ac5b276d70661c407b7e088e0144`。运行模板 SHA-256：`9e254fe3ab987d00454d754dafa7e7c389268e7b812da55ea77c28a1a51c472a`，导出版本 `tax-v1-9e254fe3ab98`。

原件同时转换为 xlsx 与 Flat OpenDocument Spreadsheet 核对：只有 `Sheet1`，A—AG 共 33 列表头，无数据行、合并区域、公式、外部引用、定义名称或 `#N/A` / `#REF!` 错误示例。运行模板的表头和值、样式与转换件一致。此前 CONTEXT.md 关于错误公式及外链的观察不适用于当前原件，已按实际结果修正；没有添加税额计算或假称保留不存在的公式。导出行复用模板单元格样式，金额使用 Decimal 和两位金额格式，身份信息防止公式注入。

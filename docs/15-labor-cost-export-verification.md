# 15 人工成本表导出验收（2026-10-02）

## 实现范围与字段口径

复用需求 13 的有效锁定批次门槛、台账、短事务生成、重试编号、导出报告、文件校验与生成/下载版本复核。新增 `/exports/labor-cost` 类型及导出中心人工成本表选项。金额不重新算薪，公司部分不再从员工工资扣除。

| 模板字段 | 来源 |
| --- | --- |
| 工资明细 C、D、H、K、M、BN | 锁定姓名、身份证、部门名称、职位、职级、银行卡快照；文本安全写入 |
| AO / AX / BF | 台账应发 / 未扣个税金额 / 公司成本 |
| AP—AR、AS / AT | 个人社保分项及合计 / 个人公积金，计入个人扣款 |
| AY—BC、BD / BE | 公司社保分项及合计 / 公司公积金，只计公司成本 |
| BG | 正常工资或独立补发、批次编号、补发原因及更正来源；未扣个税说明 |
| 主体页 F1 / B1 / E2 | 真实主体名称 / 工资期间 / 对应明细公司成本合计公式 |
| 主体页三段汇总 | 按主体引用对应员工明细实际范围；人数按员工去重，补发不增加人数 |
| AU、税后调整及申报辅助字段 | 无来源留空，主体汇总及合计也不写未知税额为零 |
| 部门二/三级层级、项目工时及其他未用辅助字段 | 不猜测历史层级或项目分摊；保留区域与样式、留空并报告 |

工资明细按主体、员工、批次排序；一个有效批次一条员工记录，更正只保留最新有效版本，补发独立保留来源。主体页按 ID 顺序使用原模板，页内 F1 显示实际主体，原工作表名称只表示模板布局；超过七个主体时复制干净模板页。使用到的原隐藏主体页显示出来，未使用页保留原空模板及可见性。

险种代码允许自由维护，只有可识别的代码映射到固定险种分项。未识别代码发出 `SOCIAL_ITEM_UNMAPPED`，金额仍计入对应个人/公司社保合计；缺分项来源留空，明细、主体分项及合计公式用 COUNT 守卫防止空值经 SUM 变为零，不猜测名称对应关系。

## 模板检查

`backend/scripts/prepare_labor_cost_template.py` 从 `docs/人工成本表-模版.xlsx` 生成 `labor-cost-v1.xlsx`，原件不变。保留原八张工作表、合并区域、样式和有效 SUM 汇总公式；清除历史主体/部门、日期、外部引用与定义名称。原工资明细第 4 行 `SUM(#REF!)` 和第 5 行历史跨主体核对公式清除；导出时第 4 行按实际明细范围重建合计。

已检查原件与运行模板的全部主体页，无历史样例残留。未知税额及税后调整的汇总公式也清除，避免空字段经 SUM 显示为零。汇总公式依赖 Excel 打开后重算；员工金额直接写入，不依赖公式缓存。

文件测试覆盖个人扣款 100.00、公司缴费 200.00、应发 1000.00、未扣个税 900.00、公司成本 1200.00；加补发 50.00 及另一同名主体后，公司成本合计 2450.00、未扣个税合计 1850.00。同名且含 `=`、`*` 的主体使用各自明细范围，不通过名称或 SUMIFS 通配符归集。八主体、每主体 60 行，共 480 行扩展，累计金额 4.80；样式、前导零/长数字文本和公式注入防护均有断言。

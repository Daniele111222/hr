# 轻算薪 PayLite

面向中小企业 HR 的轻量算薪工具 —— 定位「Excel 增强器 + 算薪核对器」。

导入花名册与月度变动 Excel，按累计预扣法计算个税、按城市计算五险一金，输出工资条 / 银行代发表 / 申报辅助表，并提供与手算 Excel 逐项对照、差异标红的核对模式。

## 产品定位

- **目标用户**：中小企业 HR（5–300 人，Windows + Excel 使用习惯，无专职 IT 部门）
- **数据不出本机**：本地存储、无账号、无云同步
- **核心壁垒**：按年份版本化的「城市社保基数 + 个税规则」开源数据包（`payroll-rules-cn`）

## 明确不做

- 不做一体化 HRMS（考勤 / 招聘 / 绩效等）
- 不接个税申报接口，只导出申报辅助格式

## 路线图

| 里程碑 | 内容 |
| --- | --- |
| M1 | 算薪引擎库 + 规则数据包（北京/上海/广州/深圳/杭州）+ 黄金测试，可独立开源 |
| M2 | Excel 导入 → 月度批量算薪 → 工资条 / 代发表导出 |
| M3 | 核对器模式（差异标红 + 原因定位）、年终奖两计税方式对比 |
| M4 | 打包 exe、历史回算、政策补差 |

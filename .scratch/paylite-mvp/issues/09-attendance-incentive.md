# 09：全公司考勤激励

**What to build（交付）：** HR 能查看全公司当期就绪情况，统一计算考勤激励并追溯其来源。

**Blocked by（前置任务）：** 08：普通工资试算与核对

**Status:** ready-for-agent

## 验收标准

- [ ] 按公司期间协调各主体数据；不齐时可保留普通试算，但不能确认最终工资。
- [ ] 激励池来自上月全主体锁定考勤扣款，候选人为本月有考勤、无规定异常、正式已转正且低于 P7 的员工。
- [ ] 按人数平均，保留两位，尾差给确定排序的最后一人；无合格员工时不生成金额并提示。
- [ ] 保存池来源、候选快照、排序、分配结果及版本；激励计入工资，不计入社保公积金基数。
- [ ] 输入变化影响公司期间就绪状态与相关批次试算，不能确认旧激励结果。
- [ ] 固定顺序锁定关联资源；验证多主体、重试、并发和金额守恒，不重复分配。

## 开始前需收敛的事项

实现前确认全公司数据齐全的判定、首次运行上月来源、尾差排序、月中主体变更归属及无候选人提示级别。不得自动将缺失上月数据视为零。

- 验证命令与结果：待填写；跳过项必须注明原因。
- 审查结论及遗留事项：待填写。

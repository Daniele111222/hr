# 04：员工 Excel 导入

**What to build（交付）：** HR 能下载员工固定模板、导入员工资料并逐行修正错误。

**Blocked by（前置任务）：** 02：员工与薪酬维护

**Status:** ready-for-agent

## 验收标准

- [ ] 提供版本化模板下载、上传、结果摘要和逐行错误页面。
- [ ] 正确行可先保存，错误行保留原始值、工作表、行列位置、错误码及修正记录。
- [ ] 保留原始文件、哈希、模板版本与字段映射，业务标识不丢失前导零或精度。
- [ ] 重复文件按约定作用域拒绝；身份证与既有员工冲突不得静默覆盖。
- [ ] 修正行重新校验，通过后仅写入一次；文件处理失败不产生不可追溯的成功状态。
- [ ] 用包含有效行、错误行、重复身份和长数字标识的工作簿验证完整流程。

## 开始前需收敛的事项

实现前收敛姓名/身份证不一致、辅助匹配、员工主档导入与工资期间关联的处理契约；不得将样例策略当作已确认业务规则。

## 完成记录

- 实现摘要：待填写。
- 验证命令与结果：待填写；跳过项必须注明原因。
- 审查结论及遗留事项：待填写。

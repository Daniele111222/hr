# 11：整批更正与有效版本切换

**What to build（交付）：** HR 能对已确认批次发起整批更正，重新核对全员并切换有效版本，同时保留旧结果。

**Blocked by（前置任务）：** 10：整批确认、锁定与台账

**Status:** ready-for-agent

## 验收标准

- [ ] 发起更正保存原批次和原因，生成覆盖原批次全体员工的替代版本，不仅复制出错员工。
- [ ] 替代版本重新试算并全员确认，继续执行输入失效与激励完整性门槛。
- [ ] 通过新增迁移协调正常批次唯一性与锁定结果保护，不能靠换批次号或关闭保护触发器绕过。
- [ ] 新版本生效与旧版本替代关系原子完成；期间汇总只取最新有效版本，切换前旧版本仍有效。
- [ ] 旧工资内容及来源保持可追溯，取消未生效更正不影响旧有效结果。
- [ ] 验证连续更正、并发应用、失败回滚及 13—16 已完成导出的版本取值回归。
- [ ] 已实际发薪差额由线下处理，不自动生成下月补扣，也不扩展跨月激励联动。

## 开始前需收敛的事项

实现前确认更正应用时点与替代版本需达到的状态。历史更正必须明确复用快照和修正输入的范围，不回读最新资料重写旧事实。

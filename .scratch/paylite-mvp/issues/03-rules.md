# 03：城市及考勤规则维护

**What to build（交付）：** HR 能按城市和生效期间维护可供算薪使用的社保、公积金与考勤规则。

**Blocked by（前置任务）：** 01：公司与组织维护

**Status:** completed

## 验收标准

- [x] 新增迁移表达城市统一固定社保缴费基数，并保存险种公司/个人比例；不得从员工薪资推导社保基数。
- [x] 公积金以固定薪资为基数，个人和公司各 5%；旧模型的可变比例和上下限不得隐式改变已确认算法。
- [x] 考勤规则表达每日 8 小时、忘打卡每次 30 元、补卡免扣及 P7 以上免扣的已确认约定。
- [x] 规则可查看版本、生效期及来源，重叠区间被拒绝，缺失或过期规则可明确识别。
- [x] 新增迁移与可审查 SQL、ORM 保持一致，不改写初始迁移；已有数据不能被静默填充假基数。
- [x] 验证新建规则、区间冲突及历史版本读取。

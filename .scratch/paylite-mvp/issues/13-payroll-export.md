# 13：工资表导出

**What to build（交付）：** HR 能从有效工资结果生成工资表，下载文件并查看导出报告。

**Blocked by（前置任务）：** 10：整批确认、锁定与台账

**Status:** ready-for-agent

## 验收标准

- [ ] 仅允许满足整批校验和状态门槛的稳定结果正式导出，失效或缺最终激励的试算不可导出。
- [ ] 保持模板工作表、表头、列顺序、合并、样式及正确公式，验证增加员工行时的结构和公式范围。
- [ ] 展示未扣个税金额；税额无来源时留空并提示，缺个税本身不额外阻断线下处理用途。
- [ ] 保存模板版本、输入批次版本、参数、文件状态和警告，失败可追溯且不可下载为成功文件。
- [ ] 文件生成不长期占用数据库事务，重试与生成期间版本变化有一致处理。
- [ ] 验证正常批次金额、长数字文本、模板结构；11、12 完成后验证更正及补发汇总。

## 开始前需收敛的事项

实现前明确正式导出所需状态、空主体/无工资员工处理、扩行公式、文件命名与警告粒度。原始公式异常先识别，不复制为已验证正确公式。

## 完成记录

- 实现摘要：待填写。
- 验证命令与结果：待填写；跳过项必须注明原因。
- 审查结论及遗留事项：待填写。

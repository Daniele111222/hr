# 05：工资期间与批次工作台

**What to build（交付）：** HR 能创建自然月工资期间和主体正常工资批次，查看批次状态与应处理员工范围。

**Blocked by（前置任务）：** 01：公司与组织维护

**Status:** ready-for-agent

## 验收标准

- [ ] 期间年月与自然月起止日一致，支持查询已有期间和批次。
- [ ] 同主体同期间重复创建正常批次被拒绝，修改批次号不能绕过约束。
- [ ] 页面展示批次状态、员工范围及数据准备情况；已存在员工时能够关联，不要求先完成员工 Excel 导入。
- [ ] 后续算薪所用全体员工范围有明确来源，不能只以导入成功行作为完整名单。
- [ ] 并发或重复创建不会产生两个正常批次；创建失败整体回滚。
- [ ] 实际发放日期的必填时点未确认前不擅自设置正式导出门槛。

## 开始前需收敛的事项

收敛员工范围的取得与刷新契约，并保证接入任务 02 后可按任职与期间验证；任务 05 可先独立验证期间与批次流程。

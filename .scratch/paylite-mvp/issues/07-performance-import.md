# 07：绩效导入与错误修正

**What to build（交付）：** HR 能导入期间绩效系数，区分缺失、错误和有效零值，并修正错误行。

**Blocked by（前置任务）：** 02：员工与薪酬维护；05：工资期间与批次工作台

**Status:** ready-for-agent

## 验收标准

- [ ] 提供固定模板下载、上传摘要、行级错误及修正重验。
- [ ] 系数必须非负且不设固定上限；缺失值与有效零值明确区分。
- [ ] 保留原文件、模板版本、原始行与规范化系数，重复事实不静默覆盖。
- [ ] 正确行先保存、错误行待修，变更可被试算失效机制识别。
- [ ] 验证缺失、零值、负数、大于一的系数、重复导入及修正重试。

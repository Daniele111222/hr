# 08：普通工资试算与核对

**What to build（交付）：** HR 能发起批次普通工资试算，查看员工金额、错误和计算步骤，并识别过期结果。

**Blocked by（前置任务）：** 03：城市及考勤规则维护；06：考勤导入与错误修正；07：绩效导入与错误修正

**Status:** completed

## 验收标准

- [x] 计算固定薪资、绩效、考勤扣款、社保、公积金及公司成本；输出明确标识未扣个税金额。
- [x] 遵循转正当月整月绩效、普通调薪整月、入离职/调动自然日折算且变更当天采用新标准。
- [x] P7 及以上免所有考勤处罚；有薪假免扣、补卡免扣、忘打卡每次 30 元。
- [x] 使用 Decimal，中间保留高精度，项目和最终结果四舍五入至两位。
- [x] 缺系数或城市规则等错误定位到员工，允许展示部分成功，但普通试算未包含最终激励时不可确认。
- [x] 保存员工、输入、规则与计算步骤快照及稳定版本/指纹；相关输入变化后页面明确提示旧试算失效。
- [x] 纯计算样例覆盖规则边界，集成验证重试、回滚和输入变更；试算结果不进入正式台账。

## 开始前需收敛的事项

已确认：零值保留并提示；负值或扣款超收入按员工报错并保留计算明细；本期跨主体调动暂不计算，列为归属错误；整月社保公积金归当月最后一个有效任职主体。试用期不考核绩效、无绩效奖金、无需绩效记录；转正当月按整月绩效规则处理。

# 15：人工成本表导出

**What to build（交付）：** HR 能生成按员工和主体归集的人工成本表，核对工资与公司承担的缴费。

**Blocked by（前置任务）：** 13：工资表导出

**Status:** completed

## 验收标准

- [x] 个人社保公积金计入个人扣款，公司部分计入公司成本，不能从员工工资重复扣除。
- [x] 员工明细与主体汇总金额一致，各有效批次只计一次。
- [x] 保持模板结构、样式、汇总公式和工作表，不扩展项目工时功能。
- [x] 无来源字段留空并在报告中说明，不把未知税额解释为零。
- [x] 验证公司/个人费用分离、跨主体汇总与模板结构；11、12 完成后补充版本和补发回归。

## 开始前需收敛的事项

不增加项目工时输入。未使用项目区域保留结构及样式，内容留空并写入导出报告。原主体模板页按实际主体 ID 顺序填充，页内公司名称取真实主体；超出七个主体时复制空模板页。不猜测历史部门层级，按主体汇总，明细保留锁定部门名称。

# 06：考勤导入与错误修正

**What to build（交付）：** HR 能为工资期间导入考勤事实、检查错误并修正后重新校验。

**Blocked by（前置任务）：** 02：员工与薪酬维护；05：工资期间与批次工作台

**Status:** completed

## 验收标准

- [x] 固定模板覆盖应出勤、迟到早退分钟、有薪/无薪请假、忘打卡、补卡和来源说明。
- [x] 原文件、原始行、规范化事实、正确/错误状态及修正记录可追溯。
- [x] 正确行允许先保存；错误行不冒充有效考勤，重复输入不静默覆盖。
- [x] 系统保存考勤事实，后续统一重算扣款，不信任导入金额作为最终结果。
- [x] 修正成功后更新可被试算识别的输入变化信息，重复修正请求不重复入账。
- [x] 验证部分成功、重验、重复文件和重复员工期间事实。

# 02：整本上传花名册与考勤并支持历史初始化

**What to build：** HR 选择工资期间后直接上传示例格式的整本工作簿，系统先导入新员工、再保存合法考勤，显示两个输入的结果与主体归集，不必拆表或整表粘贴为值。

**Blocked by：** [01：月度核算排除绩效并保留旧结果](01-monthly-without-performance.md)。

**Status:** ready-for-agent

**需求来源：** [整本导入与月度不含绩效规格](../spec.md)。

## 验收标准

- [ ] 现有导入中心提供整本入口，仅选择公司和期间；无需主体/批次选择，保留现有单项导入和考勤 v3/v2/v1 兼容。
- [ ] 接收示例固定花名册及考勤结构，允许其他工作表存在；绩效、工资/扣款结果、增减项、税务和工时不成为月度输入。
- [ ] 花名册的新员工取所选期间月初和入职日中较晚者初始化任职、固定薪资、城市和账户；已存在员工静默跳过，不覆盖或自动回填历史资料。
- [ ] 先按引擎评估验证并锁定一个本机引擎及目标部署运行时；示例必要跨表查找、日期、IFS 数组与工作日公式通过独立预期值验证，不自行扩展通用公式语义。
- [ ] 求值副本显式强制重算，故意植入 999 天等陈旧缓存后仍得到正确事实；不用普通文件转换成功当证据，不读上传文件旧缓存，不硬编码天数。
- [ ] 身份、归属及数值仍由系统复核；原文件/公式/来源位置、引擎版本及修正版本可追溯；求值只在本机隔离副本中进行，禁用宏、外部更新及网络/外部文件依赖。
- [ ] 引擎不可用、超时、退出或结果非法时无业务写入，不使用旧输出、缓存、空值或零替代；不依赖 Codex 私有运行时、本机桌面 Excel 或开发版 LibreOffice。
- [ ] 无关公式/辅助页链接不阻断合法事实；必要表达式不支持、依赖不唯一或事实不合法时，报告原工作表与原位置，不输出内部转换表的位置。
- [ ] 有效行计数不受百万行格式尺寸影响；缺身份证但有其他输入的行列为错误；文件与每个输入工作表的既有大小/行数限制有效。
- [ ] 整体结构/月份失败无业务写入；行级失败允许其他合法员工及考勤保存。资料保存后刷新本期任职范围，已有员工跳过不阻断合法考勤。
- [ ] 仅合法考勤自动补建草稿正常批次；不可编辑、归属不唯一和确认后扩张期间范围按现有规则阻断，不自动改成补发或更正。
- [ ] 最小持久化整本来源及员工/考勤子批次关联，原文件可追溯下载；新增必要 revision/SQL，历史单项关联和文件下载不失效。
- [ ] 公司、期间、文件哈希保证重复提交返回同一任务；数据库异常回滚本次写入，不出现已成功子批次却丢父关联。
- [ ] 页面显示花名册处理行/新增/失败、考勤处理行/保存/失败及主体汇总，原始数据只读；花名册既有员工不新增跳过计数或重复提示。
- [ ] 使用脱敏合成工作簿在专用测试库验证整本上传及核算；页面默认/空/加载/成功/部分失败/禁用和窄屏状态、构建及必要静态检查有实际证据。

## 实施边界

首版只识别核对过的固定结构，以受控本机引擎求值必要公式；不开发通用字段映射、工作日历管理、自写完整 Excel 引擎或后台任务平台。本票交付可上传、保存合法行、查看失败和追溯的独立闭环，依赖失败行的专项纠错在 03 完成。引擎试验是本票接入前的验收门槛，不能以开发版小样本通过替代实际部署验收。
